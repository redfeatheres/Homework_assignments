### Домашняя работа №1 — собственная реализация HashMap

Необходимо написать собственную реализацию структуры данных `HashMap`.

Обязательные методы:

- `get()` — получение значения по ключу;
- `put()` — добавление новой пары или обновление значения;
- `remove()` — удаление пары по ключу.
